# Новосибирск — природа и культура Сибири

俄文旅游介绍网站：首页两个入口（自然 / 人文），自然部分是可点击的地图页，两处景点各有一页详情（附 360° 虚拟旅游链接与图集）；人文部分是两座博物馆的详情页；另有 4 道题的小测试页。整站纯 HTML + CSS，无构建、无依赖。

## 页面清单

| 文件 | 导航 | 内容 |
| --- | --- | --- |
| `index.html` | Главная | 首屏大图、两个入口卡片、数字条、图集 |
| `nature.html` | Природа | 南部西伯利亚地图（贝加尔湖、戈尔诺—阿尔泰两个可点击标记）+ 两张景点卡 |
| `baikal.html` | Природа | 贝加尔湖：数据、名称由来、虚拟旅游链接、6 张图集 |
| `altai.html` | Природа | 戈尔诺—阿尔泰：数据、共和国概况、地形/森林/河流湖泊、status 年表、图集 |
| `culture.html` | Культура | 两座博物馆的分栏介绍 + 伊尔库茨克—塔利齐—利斯特维扬卡的路线条 |
| `taltsy.html` | Культура | 塔利齐木构建筑博物馆：缘起、博物馆之前的村落、年表、图集 |
| `museum.html` | Культура | 利斯特维扬卡贝加尔博物馆：简介、1993–2012 年表、图集 |
| `quiz.html` | Тест | 4 道选择题，答案收在 `<details>` 里 |

导航只放 4 个栏目；两处景点页与两座博物馆页从地图标记和卡片进入，`Природа` / `Культура` 在详情页保持选中状态。

## 设计说明

- 配色取自西伯利亚：深湖蓝 `#123f52`（导航、页脚、标题）、木色橙 `#c98a4b`（强调色、地图标记）、冷纸灰 `#f7f8f6`（背景）、冰蓝 `#e3edee`（色块）。
- 标题用 Georgia 衬线体，正文用系统无衬线体；卡片圆角 20–26px，内容宽 1120px。
- 地图不是手绘图：用 Natural Earth 的国界、湖泊、河流、地形区数据（50m）按墨卡托投影渲染成位图 `images/map-overview.jpg`，再用绝对定位的 HTML 标记叠在上面，因此标记本身是链接、可键盘聚焦，文字随页面字体缩放。
- 只有一个 CSS 文件、一套页头/导航/页脚；无 JavaScript，测试题答案用 `<details>` 展开。

## 打开方式

双击 `index.html` 即可，或在目录下启动一个静态服务器：

```powershell
python -m http.server 8765
```

然后访问 <http://127.0.0.1:8765>。
